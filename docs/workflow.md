# 开发过程与工程化思考

## 一、开发流程

整体采用「文档先行 → 分层实现 → 测试闭环」的推进方式，全程使用 Vibe Coding 工具（Claude Code 风格 CLI + DeepSeek V4 Pro 模型）完成编码，**不使用浏览器对话**。

| 阶段 | 动作 | 产出 | 提交前缀 |
|---|---|---|---|
| 1. SDD | 与模型确认产品边界、数据模型、API 契约，明确 `events` 为唯一事实来源 | `PRD.md` / `er.md` / `api.md` | `docs:` |
| 2. Schema | 依据 ER 生成建表脚本与 5 条样例数据 | `schema.sql` / `seed.ts` | `schema:` |
| 3. Logic | 先封装模型调用（强制 JSON + 重试），再实现嘉宾生成、发言调度、共识提取 | `llm.ts` / `core/*` | `logic:` |
| 4. API | 把纯逻辑接入 Express，落地 REST 与 SSE | `routes/` / `runner.ts` | `feat:` |
| 5. UI | 先首页后直播页，按组件边界逐个生成 | `pages/` / `components/` | `ui:` / `components:` |
| 6. Test | 先写断言再补实现（TDD），最后做 E2E 闭环 | `*.test.ts` / `*.spec.ts` | `tests:` |

关键习惯：**每次只让 AI 产出一个文件或一个函数**，并在 Prompt 中附带相关上下文（如 `schema.sql` 内容、类型定义），避免它自由发挥出不一致的接口。每完成一层立即 commit，使 Git 历史本身成为工程过程的证据。

## 二、三个典型问题与解决路径

**问题 1：模型输出不稳定，导致 JSON 解析失败**
首版直接 `JSON.parse(content)`，模型偶尔会在 JSON 前后加解释文字，流程随即中断。
**解决**：在调用层统一加三道防线 —— 请求时带 `response_format: { type: 'json_object' }`；解析失败自动重试（最多 2 次，指数退避）；重试仍失败则由业务层降级（调度器输出兜底发言，讨论继续）。
**反思**：不要指望 Prompt 保证格式，要由代码保证。**约束越靠近数据入口，系统越稳。**

**问题 2：SSE 在开发环境下不推送**
现象是页面内容不更新、轮次永远停在 0，但直接访问后端 SSE 端点却能看到事件递增。
**定位**：对比"直连 3001 正常 / 经 5173 代理异常"，判断为 Vite 开发代理缓冲了长连接。
**解决**：`EventSource` 改为直连后端（后端已开启 CORS），并在 hook 中埋入 `onopen` / `onerror` / `round_start` 日志用于自证。
**反思**：**流式协议与常规请求的传输路径不能想当然视为等价**。排查时应先在"最靠近数据源"的位置验证，再逐层向外排除。

**问题 3：状态机与真实进程脱节**
seed 数据中存在 `status = 'running'` 但无对应调度进程的记录，前端据此显示"直播中 · 第 0 轮"，用户误以为卡死。
**解决**：短期通过"打开详情对比 `status` 与 `messages` 是否为空"识别僵尸记录；长期应在服务启动时把所有 `running` 重置为 `idle` 或 `interrupted`。
**反思**：**状态字段必须是真实进程的投影，而不是可以随意写入的标记。** 数据初始化脚本尤其容易制造"看起来合理但不自洽"的脏状态。

## 三、对工程化 AI 开发的理解

1. **AI 擅长"填充"，不擅长"约束"。** 让它写一个函数很快，但决定"这个函数该放哪、输入是什么、失败怎么办"必须由人完成。所以我把工作拆成"人定契约 → AI 填实现 → 人做校验"的循环。

2. **上下文的精准度决定输出质量。** 给 AI 一个 3000 行的项目让它自己找，输出必然泛化；只给它 `schema.sql` + 一个目标文件，输出立刻可用。**控制上下文，比优化 Prompt 措辞更有效。**

3. **可测性是控制 AI 输出的杠杆。** 把核心逻辑抽成纯函数后，7 条断言就能锁死调度规则的所有边界。一旦 AI 改动越界，测试立刻报警。**测试是人和 AI 之间唯一的强制契约。**

4. **过程可追溯比结果完美更重要。** 这次开发留了 9 层 Git 提交、5 段 Prompt 记录和两个失败案例的复盘。它们证明的是"我能驾驭 AI"，而不是"AI 能写出代码"。
